# 航向差控制功能块方案

## 1. 需求分析

本项目需要设计一个TwinCAT PLC功能块，用于计算目标航向与罗盘角度之间的差值，并将结果标准化到-1800~1800范围（代表-180.0°~180.0°）。

### 功能需求：
- 输入：罗盘角度(KOMPASS_GRAD)、目标航向(KURS)，均为INT类型，单位为0.1°
- 输出：航向差(KURS_DIFF)，INT类型，范围-1800~1800
- 当罗盘角度小于0时，输出强制为0
- 当差值超过±1800时，自动进行3600的加减换算，确保结果在有效范围内

### 性能需求：
- 循环时间<10ms，满足严格的实时要求
- 支持SIL2安全兼容性

## 2. 架构设计

### 整体架构
```
MAIN Program
    └── FB_CourseDifferenceControl (功能块实例)
        ├── 输入: KOMPASS_GRAD, KURS
        ├── 输出: KURS_DIFF
        └── 内部逻辑处理
```

### 模块划分
1. **FB_CourseDifferenceControl**：核心功能块，实现航向差计算逻辑
2. **MAIN**：主程序，负责调用功能块并管理全局变量

## 3. 功能块设计

### FB_CourseDifferenceControl
**功能描述**：计算并标准化目标航向与罗盘角度的差值

| 参数类型 | 参数名称       | 数据类型 | 描述                                   |
|----------|----------------|----------|----------------------------------------|
| 输入     | KOMPASS_GRAD   | INT      | 罗盘角度(0-3599，代表0.0-359.9°)        |
| 输入     | KURS           | INT      | 目标航向(0-3599，代表0.0-359.9°)        |
| 输出     | KURS_DIFF      | INT      | 航向差(-1800-1800，代表-180.0-180.0°)  |
| 内部     | DIFF           | INT      | 临时差值变量                           |

### 逻辑流程图
```
开始
  |
  v
KOMPASS_GRAD < 0? --> 是 --> KURS_DIFF = 0
  |
  否
  v
计算 DIFF = KURS - KOMPASS_GRAD
  |
  v
DIFF > 1800? --> 是 --> KURS_DIFF = DIFF - 3600
  |
  否
  v
DIFF < -1800? --> 是 --> KURS_DIFF = DIFF + 3600
  |
  否
  v
KURS_DIFF = DIFF
  |
  v
结束
```

## 4. 数据结构设计

### 变量说明
| 变量名称       | 数据类型 | 范围       | 单位 | 描述                                   |
|----------------|----------|------------|------|----------------------------------------|
| KOMPASS_GRAD   | INT      | 0~3599     | 0.1° | 罗盘传感器输入的角度值                 |
| KURS           | INT      | 0~3599     | 0.1° | 目标航向设定值                         |
| KURS_DIFF      | INT      | -1800~1800 | 0.1° | 计算后的航向差，标准化到±180°范围内    |

### 数据范围分析
- 使用INT类型是因为TwinCAT中INT为16位，范围-32768~32767，完全满足需求
- 0.1°的分辨率足够满足大多数导航应用的精度要求
- 3600代表360°，用于差值的标准化换算

## 5. 实现建议

### 安全与性能考虑
1. **SIL2兼容性**：
   - 功能块逻辑采用简单的算术运算和条件判断，无复杂算法，符合SIL2要求
   - 所有变量均有明确的范围限制，避免溢出
   - 输入参数可以添加范围检查，确保在有效范围内

2. **性能优化**：
   - 避免使用浮点数运算，全部采用整数运算，确保计算速度
   - 逻辑简单直接，无循环和递归，循环时间<1ms，远低于10ms要求
   - 功能块内部变量使用VAR而非VAR_TEMP，避免每次调用的内存分配开销

3. **测试建议**：
   - 测试用例应覆盖所有边界条件：
     - KOMPASS_GRAD < 0 的情况
     - DIFF = 1800, 1801, -1800, -1801 的边界值
     - 正常范围内的差值计算
     - 差值刚好为±3600的情况

## 7. 形式化属性验证

本设计严格满足以下4个形式化属性：

**属性1**：如果KOMPASS_GRAD < 0，那么KURS_DIFF必须等于0
```结构化文本
IF KOMPASS_GRAD < 0 THEN
    KURS_DIFF := 0;
END_IF;
```

**属性2**：如果KOMPASS_GRAD >= 0且差值在-1800到1800之间，那么KURS_DIFF等于差值
```结构化文本
ELSIF DIFF >= -1800 AND DIFF <= 1800 THEN
    KURS_DIFF := DIFF;
```

**属性3**：如果KOMPASS_GRAD >= 0且差值>1800，那么KURS_DIFF等于差值-3600
```结构化文本
IF DIFF > 1800 THEN
    KURS_DIFF := DIFF - 3600;
```

**属性4**：如果KOMPASS_GRAD >= 0且差值<-1800，那么KURS_DIFF等于差值+3600
```结构化文本
ELSIF DIFF < -1800 THEN
    KURS_DIFF := DIFF + 3600;
```
