# 自动温室浇水系统PLC方案文档

## 1. 需求分析

### 1.1 核心功能需求
- 基于土壤湿度自动控制喷淋器启停
- 湿度低于30%时开启喷淋器
- 湿度高于70%时关闭喷淋器
- 初始状态喷淋器为关闭
- 考虑系统响应延迟，避免频繁启停

### 1.2 形式化属性要求
1. 不变式：当土壤湿度低于30%时喷淋器必须开启
   - `(SoilMoistureSensor < 30.0) = SprinklersOn`
2. 不变式：当土壤湿度大于等于70%时喷淋器必须关闭
   - `(SoilMoistureSensor >= 70.0) = (NOT SprinklersOn)`
3. 不变式：土壤湿度输入必须在0-100%范围内
   - `SoilMoistureSensor >= 0.0 AND SoilMoistureSensor <= 100.0`
4. 可达性：喷淋器必须能够被开启
   - 存在周期结束时`SprinklersOn = TRUE`的情况

### 2.2 模块划分
1. **输入处理模块**：读取土壤湿度传感器数据
2. **数据验证模块**：确保输入数据在0-100%范围内
3. **延迟逻辑处理**：实现系统响应延迟，避免频繁启停
4. **状态管理模块**：跟踪湿度变化历史和喷淋器状态
5. **输出控制模块**：根据处理结果控制喷淋器开关

## 3. 功能块设计

### 3.1 主功能块：GreenhouseWateringSystem

#### 3.1.1 接口定义
```iecst
FUNCTION_BLOCK GreenhouseWateringSystem
VAR_INPUT
    SoilMoistureSensor : REAL;   (* 土壤湿度传感器输入 (0-100%) *)
    ResponseDelay : TIME := T#5s;  (* 系统响应延迟时间 *)
END_VAR
VAR_OUTPUT
    SprinklersOn : BOOL := FALSE;         (* 喷淋器控制输出 (开/关) *)
END_VAR
```

#### 3.1.2 内部变量
```iecst
VAR
    LastMoistureReading : REAL := 0.0;
    DelayTimer : TON;                     (* 响应延迟定时器 *)
    TargetState : BOOL := FALSE;          (* 延迟后的目标状态 *)
    CurrentMoisture : REAL := 0.0;        (* 经过验证的湿度值 *)
END_VAR
VAR CONSTANT
    MIN_MOISTURE : REAL := 0.0;           (* 最小有效湿度值 *)
    MAX_MOISTURE : REAL := 100.0;         (* 最大有效湿度值 *)
    HYSTERESIS_LOW : REAL := 30.0;        (* 喷淋器开启湿度阈值 *)
    HYSTERESIS_HIGH : REAL := 70.0;       (* 喷淋器关闭湿度阈值 *)
END_VAR
```

#### 3.1.3 核心逻辑
1. **数据验证**：确保输入湿度值在0-100%范围内
2. **状态判断**：根据湿度值确定喷淋器目标状态
3. **延迟处理**：使用TON定时器实现响应延迟
4. **状态更新**：延迟时间到后更新喷淋器状态

## 4. 数据结构设计

### 4.1 湿度状态枚举 (MoistureState.TcDUT)
```iecst
TYPE MoistureState :
(
    Dry,        (* 湿度 < 30% *)
    Normal,     (* 30% ≤ 湿度 < 70% *)
    Wet         (* 湿度 ≥ 70% *)
);
END_TYPE
```

### 4.2 系统状态结构体 (SystemStatus.TcDUT)
```iecst
TYPE SystemStatus :
STRUCT
    MoistureValue : REAL;           (* 当前湿度值 *)
    MoistureState : MoistureState;  (* 湿度状态 *)
    SprinklerState : BOOL;          (* 喷淋器状态 *)
    DelayActive : BOOL;             (* 延迟是否激活 *)
    TimeRemaining : TIME;           (* 剩余延迟时间 *)
END_STRUCT
END_TYPE
```

## 5. 实现细节

### 5.1 输入验证逻辑
```iecst
(* 验证湿度输入范围 *)
IF SoilMoistureSensor < MIN_MOISTURE THEN
    CurrentMoisture := MIN_MOISTURE;
ELSIF SoilMoistureSensor > MAX_MOISTURE THEN
    CurrentMoisture := MAX_MOISTURE;
ELSE
    CurrentMoisture := SoilMoistureSensor;
END_IF;
```

### 5.2 状态判断逻辑
```iecst
(* 确定目标状态 *)
IF CurrentMoisture < HYSTERESIS_LOW THEN
    TargetState := TRUE;
ELSIF CurrentMoisture >= HYSTERESIS_HIGH THEN
    TargetState := FALSE;
ELSE
    (* 湿度在中间范围，保持当前状态 *)
    TargetState := SprinklersOn;
END_IF;
```

### 5.3 延迟处理逻辑
```iecst
(* 处理响应延迟 *)
IF TargetState <> SprinklersOn THEN
    (* 启动延迟定时器 *)
    DelayTimer(IN := TRUE, PT := ResponseDelay);
    
    IF DelayTimer.Q THEN
        (* 延迟时间到，更新状态 *)
        SprinklersOn := TargetState;
        DelayTimer(IN := FALSE);
    END_IF;
ELSE
    (* 状态一致，重置定时器 *)
    DelayTimer(IN := FALSE);
END_IF;
```

## 6. 形式化属性验证

### 6.1 不变式1验证
**要求**：当土壤湿度低于30%时喷淋器必须开启
**实现**：当`CurrentMoisture < 30.0`时，`TargetState`被设置为`TRUE`，延迟时间到后`SprinklersOn`变为`TRUE`

### 6.2 不变式2验证
**要求**：当土壤湿度大于等于70%时喷淋器必须关闭
**实现**：当`CurrentMoisture >= 70.0`时，`TargetState`被设置为`FALSE`，延迟时间到后`SprinklersOn`变为`FALSE`

### 6.3 不变式3验证
**要求**：土壤湿度输入必须在0-100%范围内
**实现**：通过输入验证逻辑确保`CurrentMoisture`始终在0-100%范围内

### 6.4 可达性验证
**要求**：喷淋器必须能够被开启
**实现**：当湿度低于30%时，系统最终会开启喷淋器，满足可达性要求
