# 自动文档归档系统PLC方案设计

## 1. 需求分析

### 功能需求
- 检测文档入口信号（DocumentInlet）和类别选择信号（CategorySelector）
- 控制传送带电机（ConveyorMotor）和四个存储仓位（StorageBin1-4）
- 当有文档进入且类别选择有效时启动传送带并打开对应存储仓位
- 无效状态下所有输出复位

### 逻辑需求
1. **启动条件**：DocumentInlet为TRUE且CategorySelector在1-4之间时，ConveyorMotor为TRUE
2. **仓位控制**：对应类别的StorageBin为TRUE，其他为FALSE
3. **复位条件**：当DocumentInlet为FALSE或CategorySelector不在1-4之间时，所有输出为FALSE

## 2. 架构设计

### 整体架构
采用单一功能块架构，集成所有控制逻辑，便于维护和测试。输入信号直接进入功能块，输出信号直接控制执行机构。

### 模块划分
- **输入模块**：处理DocumentInlet和CategorySelector信号
- **逻辑判断模块**：验证类别有效性和启动条件
- **输出控制模块**：控制传送带电机和存储仓位

## 3. 功能块设计

### 功能块名称：DocumentFilingSystem

#### 功能描述
实现自动文档归档系统的核心控制逻辑，根据输入信号控制传送带和存储仓位的动作。

#### 输入参数
| 参数名称 | 类型 | 描述 |
|---------|------|------|
| DocumentInlet | BOOL | 文档入口检测信号，TRUE表示有文档进入 |
| CategorySelector | INT | 类别选择信号，有效值1-4 |

#### 输出参数
| 参数名称 | 类型 | 描述 |
|---------|------|------|
| ConveyorMotor | BOOL | 传送带电机控制信号，TRUE表示启动 |
| StorageBin1 | BOOL | 存储仓位1控制信号，TRUE表示打开 |
| StorageBin2 | BOOL | 存储仓位2控制信号，TRUE表示打开 |
| StorageBin3 | BOOL | 存储仓位3控制信号，TRUE表示打开 |
| StorageBin4 | BOOL | 存储仓位4控制信号，TRUE表示打开 |

#### 内部变量
| 变量名称 | 类型 | 描述 |
|---------|------|------|
| ValidCategory | BOOL | 类别有效性标志，TRUE表示类别在1-4之间 |

## 4. 数据结构设计

本系统采用基本数据类型即可满足需求，无需复杂数据结构：
- BOOL类型用于开关量输入输出
- INT类型用于类别选择信号
- 内部BOOL变量用于逻辑判断

## 5. 实现建议

### 编程建议
1. 使用结构化文本（ST）语言实现，便于阅读和维护
2. 逻辑判断采用清晰的条件分支结构
3. 内部变量命名应具有明确的含义

### 测试建议
1. 测试所有输入组合，确保逻辑正确性
2. 测试边界条件（CategorySelector=0, 1, 4, 5等）
3. 测试输入信号的突变情况

### 维护建议
1. 定期检查输入输出信号的有效性
2. 保留版本历史，便于追溯变更
3. 文档化所有逻辑变更
