# 自动化图书馆书籍分拣系统PLC方案设计

## 1. 需求分析

### 1.1 功能需求
- 三个RFID阅读器（RFID1, RFID2, RFID3）检测书籍
- 传送带电机（Motor）控制
- 三个分拣箱（Bin1, Bin2, Bin3）控制

### 1.2 控制逻辑
1. 当任何RFID阅读器检测到书籍时启动传送带电机
2. RFID1检测到书籍时打开Bin1，其他箱子关闭
3. RFID2检测到书籍时打开Bin2，其他箱子关闭
4. RFID3检测到书籍时打开Bin3，其他箱子关闭
5. 当没有RFID检测到书籍时，停止电机并关闭所有箱子
6. 同一时间只有一个箱子打开
7. 电机和箱子的控制基于每个PLC周期结束时的RFID读数

### 1.3 形式化属性
1. **属性1**：任何RFID检测到书籍时电机必须启动
2. **属性2**：同一时间只能有一个箱子打开
3. **属性3**：当没有RFID检测到书籍时，所有箱子关闭且电机停止

## 3. 功能块设计

### 3.1 FB_BookSorting功能块

#### 功能描述
实现书籍分拣的核心控制逻辑，接收三个RFID阅读器的输入信号，控制传送带电机和三个分拣箱的输出，确保符合所有形式化属性要求。

#### 输入参数
| 参数名 | 类型 | 描述 |
|--------|------|------|
| RFID1 | BOOL | RFID阅读器1检测信号 |
| RFID2 | BOOL | RFID阅读器2检测信号 |
| RFID3 | BOOL | RFID阅读器3检测信号 |

#### 输出参数
| 参数名 | 类型 | 描述 |
|--------|------|------|
| Motor | BOOL | 传送带电机控制输出 |
| Bin1 | BOOL | 分拣箱1控制输出 |
| Bin2 | BOOL | 分拣箱2控制输出 |
| Bin3 | BOOL | 分拣箱3控制输出 |

#### 内部变量
| 变量名 | 类型 | 描述 |
|--------|------|------|
| v_RFIDStatus | INT | RFID检测状态 0=无检测, 1=RFID1, 2=RFID2, 3=RFID3 |
| v_PreviousStatus | INT | 上一周期状态，用于状态保持 |

#### 核心逻辑
1. **状态检测**：根据RFID输入信号确定当前检测状态
2. **电机控制**：任何RFID检测到书籍时启动电机
3. **分拣箱控制**：根据当前状态打开对应分拣箱，确保同一时间只有一个箱子打开
4. **安全保护**：双重保障机制确保符合形式化属性要求

## 5. 实现建议

### 5.1 硬件实现建议
1. **RFID阅读器**：选用高频或超高频RFID阅读器，确保检测距离和精度
2. **传送带电机**：选用带编码器的伺服电机或变频电机，实现精确速度控制
3. **分拣箱执行机构**：选用电磁阀控制的气动推杆或电动推杆
4. **I/O模块**：选用数字量输入模块（≥4点）和数字量输出模块（≥4点）

### 5.2 软件实现建议
1. **PLC周期**：建议设置为10ms-50ms，确保实时性和稳定性
2. **防抖动处理**：可在RFID输入信号处添加100ms-200ms的防抖动滤波
3. **故障诊断**：添加输入信号断线检测、电机过载保护等故障诊断逻辑
4. **可视化界面**：开发HMI界面显示分拣数量、系统状态和故障信息

### 5.3 调试建议
1. **单步调试**：先测试单个RFID阅读器和对应分拣箱的控制逻辑
2. **并发测试**：测试多个RFID阅读器同时检测的优先级处理逻辑
3. **边界测试**：测试从有检测到无检测的状态切换逻辑
4. **负载测试**：模拟高频率书籍分拣场景，测试系统稳定性

## 7. 形式化属性验证

### 7.1 属性1验证
```
任何RFID检测到书籍时电机必须启动
→ 当RFID1∨RFID2∨RFID3为TRUE时，Motor必须为TRUE
→ 实现：Motor := (v_RFIDStatus <> 0)
```

### 7.2 属性2验证
```
同一时间只能有一个箱子打开
→ Bin1∧Bin2∧Bin3中最多有一个为TRUE
→ 实现：通过CASE结构天然保证互斥性，并添加双重保障逻辑
```

### 7.3 属性3验证
```
当没有RFID检测到书籍时，所有箱子关闭且电机停止
→ 当RFID1∧RFID2∧RFID3为FALSE时，Motor∨Bin1∨Bin2∨Bin3必须为FALSE
→ 实现：当v_RFIDStatus=0时，强制设置所有输出为FALSE
```
