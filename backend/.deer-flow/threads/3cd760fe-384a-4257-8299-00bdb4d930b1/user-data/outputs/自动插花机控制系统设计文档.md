# 自动插花机控制系统PLC功能块详细设计文档

## 1. 概述
本文档详细描述了自动插花机控制系统的PLC功能块设计方案，包括需求分析、架构设计、功能块实现和测试建议。

## 2. 需求分析

### 2.1 输入信号
- **FlowerTypeSensor(INT)**：花型传感器输入，有效值为1和2
- **FlowerColorSensor(INT)**：花色传感器输入，有效值为1和2

### 2.2 输出信号
- **ArrangingMechanism(INT)**：插花机构控制输出，有效值为0-4
- **ConveyorBelt(BOOL)**：传送带控制输出，TRUE表示运行，FALSE表示停止

### 2.3 控制逻辑
1. 当FlowerTypeSensor为1且FlowerColorSensor为1时，ArrangingMechanism设为1
2. 当FlowerTypeSensor为1且FlowerColorSensor为2时，ArrangingMechanism设为2
3. 当FlowerTypeSensor为2且FlowerColorSensor为1时，ArrangingMechanism设为3
4. 当FlowerTypeSensor为2且FlowerColorSensor为2时，ArrangingMechanism设为4
5. 其他任何组合时，ArrangingMechanism设为0
6. 当ArrangingMechanism不为0时，ConveyorBelt设为TRUE，否则设为FALSE

## 3. 架构设计

### 3.1 整体架构
系统采用单一功能块架构，所有控制逻辑集中在`FB_FlowerArrangement`功能块中，便于维护和扩展。

### 3.2 模块划分
| 模块名称 | 功能描述 |
|---------|---------|
| FB_FlowerArrangement | 核心控制模块，实现所有逻辑判断和输出控制 |

## 4. 功能块详细设计

### 4.1 FB_FlowerArrangement 功能块

```iecst
FUNCTION_BLOCK FB_FlowerArrangement
VAR_INPUT
    FlowerTypeSensor: INT; // 花型传感器输入 (1或2)
    FlowerColorSensor: INT; // 花色传感器输入 (1或2)
END_VAR
VAR_OUTPUT
    ArrangingMechanism: INT; // 插花机构输出 (0-4)
    ConveyorBelt: BOOL; // 传送带控制输出
END_VAR

// 控制逻辑实现
CASE FlowerTypeSensor OF
    1:
        CASE FlowerColorSensor OF
            1: ArrangingMechanism := 1;
            2: ArrangingMechanism := 2;
            ELSE: ArrangingMechanism := 0;
        END_CASE;
    2:
        CASE FlowerColorSensor OF
            1: ArrangingMechanism := 3;
            2: ArrangingMechanism := 4;
            ELSE: ArrangingMechanism := 0;
        END_CASE;
    ELSE:
        ArrangingMechanism := 0;
END_CASE;

// 传送带控制逻辑
ConveyorBelt := (ArrangingMechanism <> 0);

END_FUNCTION_BLOCK
```

#### 4.1.1 输入参数
| 参数名称 | 数据类型 | 范围 | 描述 |
|---------|---------|------|------|
| FlowerTypeSensor | INT | 1-2 | 花型传感器输入，1表示类型1，2表示类型2 |
| FlowerColorSensor | INT | 1-2 | 花色传感器输入，1表示颜色1，2表示颜色2 |

#### 4.1.2 输出参数
| 参数名称 | 数据类型 | 范围 | 描述 |
|---------|---------|------|------|
| ArrangingMechanism | INT | 0-4 | 插花机构控制输出，0表示无动作，1-4表示不同的插花动作 |
| ConveyorBelt | BOOL | TRUE/FALSE | 传送带控制输出，TRUE表示运行，FALSE表示停止 |

#### 4.1.3 内部变量
无额外内部变量，所有逻辑直接通过输入计算输出

## 5. 数据结构设计

本系统无需复杂数据结构，直接使用基本数据类型即可满足需求：
- **INT**：用于传感器输入和机构控制输出
- **BOOL**：用于传送带控制输出

## 6. 实现建议

### 6.1 TwinCAT规范遵循
1. **命名规范**：使用匈牙利命名法，功能块以`FB_`开头，变量名采用 PascalCase 命名
2. **代码结构**：使用CASE语句实现清晰的分支逻辑，避免嵌套IF语句
3. **错误处理**：所有未定义的输入组合都将使ArrangingMechanism设为0，确保系统安全
4. **性能优化**：逻辑采用纯组合逻辑，无循环或延时，确保实时响应

### 6.2 扩展建议
- 可考虑添加输入参数范围检查和错误输出
- 可添加状态指示灯输出，便于故障诊断
- 可考虑添加手动/自动模式切换功能
