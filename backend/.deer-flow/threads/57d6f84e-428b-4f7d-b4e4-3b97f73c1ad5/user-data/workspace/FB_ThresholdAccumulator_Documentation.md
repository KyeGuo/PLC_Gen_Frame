# FB_ThresholdAccumulator功能块文档

## 1. 功能概述
FB_ThresholdAccumulator是一个用于阈值累积计算的PLC功能块，根据输入值进行计算并输出符合特定规则的结果。

## 2. 输入输出定义

### 输入变量
| 名称 | 类型 | 描述 |
|------|------|------|
| i | DINT | 输入整数值 |

### 输出变量
| 名称 | 类型 | 描述 |
|------|------|------|
| o | DINT | 输出整数值 |

## 3. 内部变量
| 名称 | 类型 | 描述 |
|------|------|------|
| s1 | DINT | 内部中间计算变量，每次调用时初始化0 |

## 4. 逻辑说明

### 执行步骤
1. **初始化**：每次调用功能块时，将内部变量s1初始化为0
2. **输入处理**：如果输入i大于0，将其值添加到s1
3. **阈值检查**：如果s1等于42，添加8000到s1
4. **输出处理**：
   - 如果s1小于0，设置输出o为0
   - 否则，将输出o设置为当前s1的值，但不超过DINT最大值

### 形式化属性保证
1. **输出始终非负**：通过MAX(0, s1)确保输出值不会为负
2. **输入非正处理**：当i≤0时，s1保持为0，因此输出o=0
3. **输出范围限制**：通过MIN(s1, 2147483647)确保输出不超过DINT类型最大值

## 5. 使用示例

```st
PROGRAM MAIN
VAR
    accumulator : FB_ThresholdAccumulator;
    inputValue : DINT;
    outputValue : DINT;
END_VAR

// 示例1：输入42，输出8042
inputValue := 42;
accumulator(i := inputValue, o => outputValue);
// outputValue = 8042

// 示例2：输入-10，输出0
inputValue := -10;
accumulator(i := inputValue, o => outputValue);
// outputValue = 0

// 示例3：输入2147483647，输出2147483647
inputValue := 2147483647;
accumulator(i := inputValue, o => outputValue);
// outputValue = 2147483647
```

## 6. 测试用例

| 输入i | 预期输出o | 说明 |
|-------|-----------|------|
| 0 | 0 | 输入为0 |
| -10 | 0 | 输入为负数 |
| 42 | 8042 | 达到阈值，添加8000 |
| 41 | 41 | 未达到阈值 |
| 8000 | 8000 | 正常输入 |
| 2147483647 | 2147483647 | DINT最大值 |
| 2147483648 | 2147483647 | 溢出情况，输出最大值 |

## 7. 注意事项
- 功能块为单次调用型，每次调用都会重新初始化s1为0
- 输入值超出DINT范围时，TwinCAT会自动进行溢出处理
- 输出值始终保证在0到2147483647之间
