# HomeBrewingSystem PLC控制系统

## 项目概述
这是一个用于家庭酿酒系统的PLC控制系统，基于Beckhoff TwinCAT平台开发，实现自动化酿造流程控制。

## 功能特性
1. **温度自动控制**：当温度低于65°C时自动激活加热元件
2. **搅拌电机控制**：水流量高于0.5单位时激活搅拌电机
3. **啤酒花自动投放**：酿造开始5小时后自动投放啤酒花
4. **发酵罐自动控制**：酿造开始48小时后自动激活发酵罐
5. **完整的状态机管理**：包含待机、酿造、发酵、完成、故障等状态
6. **故障诊断与报警**：实时监测系统状态，异常时自动进入安全状态

## 文件结构
```
├── FB_HomeBrewingSystem.TcPOU      # 主控制功能块
├── FB_TemperatureControl.TcPOU      # 温度控制模块
├── FB_FlowControl.TcPOU            # 流量控制模块
├── FB_TimeControl.TcPOU            # 时间控制模块
├── GVL_HomeBrewingSystem.TcGVL     # 全局变量列表
├── DT_HomeBrewingSystem.TcDUT      # 数据类型定义
├── Main.TcPOU                      # 主程序入口
└── README.md                       # 项目说明文档
```

## 安装与配置
1. 将所有文件复制到TwinCAT项目目录
2. 在TwinCAT中添加这些文件到项目
3. 配置输入输出变量与实际硬件的映射
4. 根据实际需求调整酿造参数

## 操作说明
1. 设置`g_BrewingStartTime`为当前时间开始酿造
2. 系统自动根据传感器输入控制各设备
3. 可通过`g_BrewingParams`调整酿造工艺参数
4. 系统状态可通过`g_SystemState`实时监控
5. 报警信息可通过`g_Alarm*`变量查看

## 技术规范
- 符合IEC 61131-3标准
- 基于TwinCAT 3开发
- 支持结构化文本(ST)编程语言
- 所有输入输出变量均进行有效性检查
- 故障安全设计，异常时自动进入安全状态

3. 备份酿造参数和系统配置

5. 遵循安全操作规程进行维护```
