# 颜色分类机械臂控制系统PLC方案设计

## 1. 需求分析

### 1.1 系统概述
本系统为颜色分类机械臂控制系统，通过颜色传感器检测物品颜色，控制机械臂将物品分拣到对应颜色的料箱中。

### 1.2 输入输出变量
- **输入变量**:
  - `ColorSensorRed(BOOL)`: 红色颜色传感器检测信号
  - `ColorSensorGreen(BOOL)`: 绿色颜色传感器检测信号
  - `ColorSensorBlue(BOOL)`: 蓝色颜色传感器检测信号

- **输出变量**:
  - `RoboticArmMove(BOOL)`: 机械臂移动控制信号
  - `BinRed(BOOL)`: 红色料箱激活信号
  - `BinGreen(BOOL)`: 绿色料箱激活信号
  - `BinBlue(BOOL)`: 蓝色料箱激活信号

### 1.3 形式化属性要求
1. 当任何颜色传感器检测到颜色时，机械臂`RoboticArmMove`为true
2. 当没有颜色检测时，机械臂`RoboticArmMove`为false
3. 同一时间只能激活一个料箱或都不激活
4. 红色料箱`BinRed`仅在红色传感器检测到颜色时激活

## 2. 架构设计

### 2.1 整体架构

```
│  │  - ColorSensorBlue               │  │

│                                         │
│  ┌───────────────────────────────────┐  │
│  │  逻辑处理:                        │  │
│  │  - 传感器状态检测                  │  │
│  │  - 机械臂移动控制                  │  │
│  │  - 料箱激活控制                    │  │

│                                         │
│  ┌───────────────────────────────────┐  │
│  │  输出变量:                        │  │

```

### 2.2 模块划分
系统仅包含一个核心功能块，所有逻辑在内部实现：
- 传感器状态检测模块
- 机械臂移动控制模块
- 料箱激活控制模块

## 3. 功能块设计

### 3.1 功能块FB_ColorSortingRobot

**功能描述**: 实现颜色分类机械臂的完整控制逻辑，包括传感器状态检测、机械臂移动控制和料箱激活控制。

**输入参数**:
| 参数名称         | 类型  | 描述                  |
|------------------|-------|-----------------------|
| ColorSensorRed   | BOOL  | 红色传感器检测信号    |
| ColorSensorGreen | BOOL  | 绿色传感器检测信号    |
| ColorSensorBlue  | BOOL  | 蓝色传感器检测信号    |

**输出参数**:
| 参数名称        | 类型  | 描述                  |
|-----------------|-------|-----------------------|
| RoboticArmMove  | BOOL  | 机械臂移动控制信号    |
| BinRed          | BOOL  | 红色料箱激活信号      |
| BinGreen        | BOOL  | 绿色料箱激活信号      |
| BinBlue         | BOOL  | 蓝色料箱激活信号      |

**内部变量**:
| 参数名称      | 类型  | 描述                  |
|---------------|-------|-----------------------|
| SensorActive  | BOOL  | 至少一个传感器激活标志|

## 4. 数据结构设计
本系统无需复杂数据结构，仅使用基本BOOL类型变量。

## 5. 实现建议

### 5.1 逻辑实现说明
1. **机械臂移动控制**: 通过逻辑或运算检测是否有传感器激活，直接控制机械臂移动信号
2. **料箱激活控制**: 通过互斥逻辑确保同一时间只能激活一个料箱，同时确保料箱仅在对应传感器激活且其他传感器未激活时激活

### 5.2 安全考虑
- 建议在实际应用中添加传感器故障检测逻辑
- 考虑添加机械臂急停输入接口
- 建议添加超时保护机制

### 5.3 扩展建议
- 可添加更多颜色传感器支持
- 可添加物品计数功能
- 可添加通信接口实现远程监控
